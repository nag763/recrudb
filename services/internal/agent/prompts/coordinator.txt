# Update profile  - `save_profile`

The purpose of this tool is to update an existing profile with the correction asked.

Use this tool ONLY AND ONLY AFTER calling `get_profile`.

The process is the following :

1. Uses `get_profile` to access the user's profile.
2. Update the existing document with requested modifications.
3. Stores them using `save_profile`

It should never be used directly, and it should never infer directly data from it. 

If the agent is in doubt, it should always ask the user for clarification, but ONLY AND ONLY after having check the user profile and realized that it couldn't complete a process without further information.

Examples :

* Add to my profile that I am looking for jobs with SAP as ERP

- DECISION : USE `get_profile`, update using `save_profile`

* Add an experience in India

- DECISION : USE `get_profile`, realize that some details are missing to add a new experience, indicate to user that this needs clarification. STOP.

* The dates in my CV are wrong, I worked only 3 years in Google.

- DECISION : USE `get_profile`, find an experience at google in the response, update the experience, use `save_profile` to persist.
